# Chord Pocket

Chord Pocket is a mobile-friendly guitar chord reference and flashcard app. It includes 576 structured chord voicings across 12 roots and 17 chord families.

## Features

- Browse and search the full chord collection.
- Filter by one or more chord families.
- Show the first shape for each chord or every available shape.
- Add and remove chords from a personal practice set with one tap.
- Practice saved chords as flashcards: the diagram hides for three seconds, then rate yourself **Nailed it** or **Missed it**.
- Missed chords automatically re-enter the rotation until you nail every chord in the set.
- Reveal each flashcard manually or automatically after three seconds.
- Use the installed app offline after its assets have been cached.

Chord diagrams are rendered in the browser from structured fret, finger, barre, tuning, and root-note data. Root notes are marked with a square.

## Running locally

The application has no build step or runtime dependencies. Serve the repository root with any static web server, then open `dist/`:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/dist/` in a browser. Opening `dist/index.html` directly is not recommended because service workers require an HTTP origin.

## Project layout

```text
dist/                  Deployable static application
  app.js               Interface and chord-diagram renderer
  chords.json          Structured chord collection
  index.html           Application shell
  styles.css           Responsive styling
  sw.js                Offline cache service worker
tools/
  audit-chords.mjs     Chord-data integrity audit
```

Selections are stored locally in the browser under `chord-pocket-selected-v1`.

## Validation

Run the complete chord-data audit before committing changes to `dist/chords.json`:

```sh
node tools/audit-chords.mjs
```

The audit verifies all 576 records, chord-tone membership, finger assignments, barre consistency, and the six-string data shape.

For a quick JavaScript syntax check:

```sh
node --check dist/app.js
node --check dist/sw.js
```

## Content policy

The repository contains structured musical facts and diagrams generated by the application. Do not add third-party scans, page captures, copied artwork, publication page references, or extraction provenance.

## Deployment

The deployable site is the contents of `dist/`. The included web app manifest and service worker support installation and offline use on compatible browsers.
